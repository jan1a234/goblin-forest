Goblin Forest 1.0 für **Minecraft Java 26.2** (Fabric). 1-gegen-1-Lane-Strategie mit Goblin-Clans, inspiriert von *Clan Wars: Goblin Forest*.

**Installieren:** die `goblinforest-1.0.0.jar` unten zusammen mit der [Fabric API](https://modrinth.com/mod/fabric-api) für 26.2 in den `mods`-Ordner legen, auf dem Server und bei beiden Spielern. Benötigt Fabric Loader 0.19.5 oder neuer und Java 25.

**Loslegen:** beide tippen `/gf join`, dann `/gf start`. Alleine gegen den Computer: `/gf start ki` (oder `ki leicht|normal|schwer`), als Serie: `/gf start bo3`. `/gf help` zeigt alles.

### Was drin ist

- **Acht Goblin-Typen**: Sklave, Krieger, Bogenschütze, Assassine, Schamane, Wolfsreiter (auf einem Warg), Troll und Katapult. Jeder Goblin sammelt eigene Erfahrung und steigt bis zum Champion auf, Champions bekommen eine Spezialfähigkeit.
- **Häuptling** (du selbst) mit Stufe 1 bis 10, Fähigkeitspunkten, Blutrausch, Kampfstampfer und Raserei.
- **Fünf Zauber**: Feuerball, Heilende Pilze, Wurzelfessel, Blitzsturm, Meteor.
- **Festungsausbau**: Turm, Mauern, Hütten, Kanone, Goldmine, Ausbildung, Ausdauer; dazu Upgrades für Rüstung, Angriff und Reichweite je Einheitentyp.
- **Wirtschaft**: Grundeinkommen, Kopfgeld je nach Frontlage, Ruf-Stufen schalten Einheiten und Zauber frei.
- **KI-Gegner** in drei Stufen, **Best-of-3/5-Serien** und **Sudden Death** nach 25 Minuten.
- **Kriegsmenü** (B), Schnelltasten, eigenes HUD, feste Verfolgerkamera mit Zoom (Bild↑/Bild↓) und **Kommandoansicht** (linke Alt-Taste) mit Blick über das Schlachtfeld.
- **Eigene Klänge**: Kriegstrommeln während der Schlacht, Kriegshorn, Münzklimpern.
- Deutsch und Englisch.

Jeder Build wird automatisch getestet: ein komplettes Match auf einem echten Server und ein Durchlauf im echten Minecraft-Client mit [Bildschirmfotos](https://github.com/jan1a234/goblin-forest/tree/ci-screenshots).
