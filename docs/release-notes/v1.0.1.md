Goblin Forest 1.0.1 für **Minecraft Java 26.2** (Fabric). Kleines Update für einen besseren Einstieg ins Match.

**Installieren:** die `goblinforest-1.0.1.jar` unten zusammen mit der [Fabric API](https://modrinth.com/mod/fabric-api) für 26.2 in den `mods`-Ordner legen, auf dem Server und bei beiden Spielern (die alte 1.0.0 vorher entfernen). Benötigt Fabric Loader 0.19.5 oder neuer und Java 25.

### Neu

- **Wegweiser beim Matchstart:** Du bist selbst der Häuptling. Bis du deine Festung verlassen hast, zeigt das HUD jetzt „Du bist der Häuptling! Lauf mit W/A/S/D durchs Tor aufs Schlachtfeld“ (mit deinen eingestellten Bewegungstasten). Der Hinweis erscheint zu Beginn jeder Runde wieder.
- Der Untertitel bei „Kampf!“ und die Steuerungsnachricht im Chat sagen das ebenfalls.
- README: Abschnitt „Du bist selbst der Häuptling“ und W/A/S/D in der Steuerungstabelle.
